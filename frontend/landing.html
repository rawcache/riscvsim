01

Registers update as you step.

Every instruction writes a result. The register file shows you exactly which register changed, what it changed to, and how many cycles the operation took. Nothing is hidden behind an abstraction layer.

02

Every instruction has a visible effect.

RISC-V is easier when the machine state is not hidden. Below every instruction, a pseudo-C translation describes the exact computation — register operands, memory addressing, and control flow included.

03

The stack becomes visible.

Frame boundaries, saved registers, and the stack pointer are labeled and updated in real time. Push and pop, call and return — every frame transition is explicit and traceable.
