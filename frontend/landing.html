              REGISTER FILE
              
Watch every register change live.

              
The register file updates in real time as you step through execution. Changed registers flash with a brief highlight so your eye goes exactly where the action is.

            


            

              PSEUDO-C TRANSLATOR
              
See the instruction. Understand the effect.

              
Below every instruction in the simulator, a plain English pseudo-C translation explains exactly what changed and why. No more black-box execution.

            


            

              STACK VISUALIZER
              
The stack is no longer invisible.

              
Every push and pop is visualized as the stack grows and shrinks. Frame boundaries are labeled. sp is always visible. You never lose track of where you are.

ADDI

            
Add an immediate constant to a register.

            addi x5, x0, 10
          

          

            
Immediate setup for constants and loop counters

            
Use addi for quick register updates without touching memory. It shows up everywhere: loop indexes, stack pointer movement, and small constant setup.

            x5 ← x0 + 10
